# Change Log

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/) and this
project adheres to [Semantic Versioning](http://semver.org/).

## [1.2.1] - 2025-12-30

### Fixed

- Fix issue where the overlay message was not being set in breakout rooms when
  the users tried to change it for "All rooms".

### Changed

- Update dependencies to latest versions.
- Configure vite to simplify development setup.
- Improve README with better instructions for development setup and how to use
  it when we have breakout rooms.

## [1.2.0] - 2025-08-13

### Added

- Support for i18n and two languages: English and Dutch.

### Changed

- Update dependencies to latest versions.
- Move the buttons from the settings panel to the toolbar.

## [1.1.0] 2024-08-30

### Added

- Support for breakout rooms.

## [1.0.0] - 2024-06-03

### Added

- Change message overlay for the main room in a VMR (only Pexip Infinity v35 and
  later).
